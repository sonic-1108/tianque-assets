# 天阙 Tian Que

3D 动作对战网页游戏。狂刃·霍岩 / 夜鸮 / 梵音 / 灵雀 / 慈航。

本地运行：`npm install` 然后 `npm run dev`

## 青岚采石场：单人寻材试验

大厅点击「青岚采石场 · 单人寻材」，或在地图列表选择青岚采石场后出征。
固定使用狂刃挑战一名试炼守卫；在「造物志」记下寻材目标，击败守卫后靠近掉落标本，获得 1 份精铁和 1 份追踪原材（追踪精铁时只获得精铁）。
材料保存于当前浏览器的 `tq_adventure_v1`，刷新后保留。按 M 回大厅重新出发。
此地图暂不支持联机。造物志的 3D 工匠台可旋转查看六种原材、阅读潜在用途，并制作鸣雷刃芯、沉岳回响核、霜息缠柄三种改造。一次装备一件，下次单人采石场出发时生效；其他竞技地图不应用改造加成。

鸣雷刃芯每第三次有效近战命中增加 35% 伤害；沉岳回响核增加重击伤害及击退；霜息缠柄让完美闪避或格挡后的近战反击回复生命。介绍里的其他潜在用途仍是设计方向，不代表已有功能。旧铁料存档自动保留，材料和已制作改造写入同一份存档并参与账号云备份。

鼠标锁定被浏览器拒绝时，可在场景内移动鼠标转视角；移动到界面控件或暂停时不处理镜头输入。

验证：`npx tsc --noEmit -p .`、`npm run build`。
存档测试：`npx tsc --ignoreConfig src/adventure.ts --target ES2022 --module ESNext --outDir .adventure-test --skipLibCheck`，然后 `node --test tools/tests/adventure.test.mjs`。
镜头测试：Node 22.13+ 执行 `node --test tools/tests/camera-input.test.cjs`。

### 账号档案与云存档

- 玩家资料与进度存入 Cloudflare 的 D1 / Durable Object SQLite，不提交 GitHub。登录恢复码对应固定玩家 ID；旧版公开在线列表仍仅使用会话 ID，账号身份通过带凭据的 `/api/heartbeat` 发送。
- `战绩 → 我的战绩` 中查看云存档状态，每 20 秒备份钱包、手表、原材与改造、洛城职位及任务。换设备或换账号发现不同版本时暂停同步，由玩家选择保留本机或读取云端；读取会刷新游戏，原本机进度可通过“恢复本机备份”找回。
- 更新以前的游玩时间无法补算。后台时间为心跳估算的可见游戏页面活跃时长，断线超过 45 秒不补算。客户端上报的进度不是反作弊依据。
- `admin.html` 增加按昵称 / 账号 ID 搜索、分页和玩家详情。新增档案接口在服务端验证每日口令；未配置 `ADMIN_SEED` 时拒绝访问。部署流程只把派生哈希写入 Worker，不把种子写入代码。
- 数据表只增加 `saves` 与 `activity`，保留已有账号、战绩。存档用版本号条件写入，拒绝跨设备陈旧版本覆盖；服务失败时保留本机进度。
- 开发验证（Node 24）：`node --test tools/tests/profiles.test.mjs tools/tests/cloud-save.test.cjs`。包含 SQLite 接口、鉴权、存档版本冲突、换号隔离及旧存档兼容测试。

## 实验地图 · 青岚遗谷

大厅独立入口，原竞技模式保留。营地按 F 接受石师傅的委托，靠近西侧雷纹铜、东侧寒髓石或北侧回响晶停留 2.5 秒采集。至少完成两处后回营停留即可交付，每处两份原材并附赠一份精铁。北侧守卫是可选挑战，奖励两份追踪原材。倒下五秒后无限回营，随身样本保留；主动离开则放弃未交付样本。入库原材与既有背包、云存档共用，已装备改造也适用于实验地图。


### 百业试炼（独立账号成长模式）

大厅的「百业试炼」接取契约。1–29级可使用全部6个已上线职业、所有可用地图；新职业与地图组合首次完成额外奖励400经验。契约要求实战伤害、存活时间与返回出发点后按F交付，失败不奖励，暂停不计时。30级须两步确认本命职业，之后只能用该职业进入本模式，地图不锁。3枚定职后的专精印解锁破势（伤害+8%）或守心（最大生命+15%）。自由对战仍可试用其他职业。

百业等级独立于旧对战修为。账号进度、职业选择、契约与领奖记录存于账号服务器 `careers` 表，客户端离线时不发奖励。职业锁定和重复领奖由服务器校验；战斗数据目前仍由客户端报告，不具备服务器权威战斗反作弊。当前是单人契约原型，不是完整MMO。

### 武器制造与静音测试

铸兵坊支持刀刃、握柄、晶核和实时外观调整；制造消耗材料，保存的武器可用于实验遗谷。遗谷双方20000生命，死亡会掉落武器，靠近可拾回。外观比例不改变攻击距离或伤害。

代理测试入口始终附带 `?silent=1`，禁止创建游戏音频上下文；不更改玩家声音偏好。
